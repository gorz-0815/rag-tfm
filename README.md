# rag-tfm

A small RAG (Retrieval-Augmented Generation) demo: ask questions about technical manuals and get grounded, cited answers, with end-to-end tracing and a comparative evaluation against a no-RAG baseline.

**Status: planning stage.** No implementation yet — the current plan lives in [`openspec/changes/rag-tfm-mvp/`](openspec/changes/rag-tfm-mvp/) as an [OpenSpec](https://github.com/Fission-AI/OpenSpec) change proposal (proposal, specs, design, tasks). This README will be filled in once the MVP is implemented.
